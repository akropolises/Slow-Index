# SlowTechApp

絵を描く体験と、AIとの対話によるふりかえりを組み合わせた、アートセラピー・マインドフルネス系のアプリです。

## アプリ概要

数滴の「絵の具」を落とすように色を選んでいくと、それが少しずつ積み重なって一枚の絵になっていきます。絵を描き終えたあとは、複数のAIがその絵を眺めながら、ジャッジせずにそっと感想を語り合う対話(音声読み上げ付き)を聞くことができます。

## 主な画面フロー

1. **キャンバス画面**: 今育っている絵を眺める入口
2. **静寂画面(30秒)**: 数字のカウントダウンなしで、光の脈動と振動(Haptics)を軸にした静かな時間
3. **出口色選択画面**: 4色から今の気分に近い色を選び、絵に一滴加える
4. **完成画面 / ギャラリー画面**: 完成した絵を見返す。「サンプル」の絵ではAI対話(TTS)を再生できる（まだ自然な音声にはなっていない）

## 技術スタック

- [Expo](https://expo.dev/) (React Native) / React Navigation
- `expo-speech`: AI対話の音声読み上げ(TTS)
- `expo-haptics`: 静寂画面の振動フィードバック
- EAS Update: OTA配信によるアプリ更新

## セットアップ

```bash
npm install
npx expo start
```

ブラウザで手軽に確認したい場合は `npx expo start --web` でも起動できます(ただしTTS/Hapticsの一部挙動はネイティブ環境と異なります)。

## 共有・配布方法

このアプリは `eas-cli update` で `preview` ブランチにOTA公開する運用です。Expo Goをインストールした端末であれば、公開済みのQRコード/リンクから開発ビルドなしにアプリを試せます。

```bash
npx eas-cli update --branch preview --message "変更内容" --non-interactive --environment preview
```

## 既知の制約・注意点

- Web版はSkia/一部音声APIの挙動がネイティブと異なるため、最終確認は実機(Expo Go)での動作を優先してください
