# スローテックアプリ 顧客価値・体験

ペルソナ([ペルソナ.md](./ペルソナ.md))と仕様書([仕様書.md](./仕様書.md))を踏まえた、顧客価値(バリュープロポジション)と体験の明文化。

## 顧客価値(バリュープロポジション)

**誰に**：Fastに生きる人(タスク・成果・効率で日々を駆け抜け、休むことに罪悪感や抵抗を感じている人)

**どんな課題を抱えていて**：

- 予定と予定の間に、自分の感情や疲労に気づく隙間がない(ペルソナ①③)
- 内省・休息の習慣を試みても、タスク化・評価化してしまい続かない(ペルソナ②)
- 「休むこと」自体を、パフォーマンスの敵だと感じている(ペルソナ①)
- 自分のために時間を作る余力がない(ペルソナ③)

**このアプリが提供する価値**：

1. **隙間に自動的に差し込まれる、30秒だけの休息**(自分で時間を作らなくていい)
2. **評価・正解のない、ジャッジされない体験**(続けること自体がタスク化しない)
3. **「今の自分」を、良い悪いのジャッジなしに多面的に受け止められる感覚**(AIとの対話を通じたメタ認知)
4. **Slowを取り入れることでFastの効率が上がるという実感**(極地反転)

**一言で言うと**：

> 「時間を作らなくていい、正解を求められない、それでも自分をちゃんと受け止められる、30秒の休息」

## 体験の明文化(カスタマージャーニー)

| フェーズ | 状態 | このアプリが与えるもの |
|---|---|---|
| **Before(通知前)** | 次の予定に向けて頭がすでに次モードに入っている。自分の状態に気づく余白がない | - |
| **導入(通知)** | 「あと5分」の隙間にFastの言葉(パフォーマンス最大化)で軽く誘われる | ハードルの低い入口 |
| **リセットタイム(30秒)** | 目を閉じ、遠くの音・身体感覚など「自分の外側/内側」へ意識が向き、言葉や論理が自然と抜けていく | 強制的にではなく、自然にSlowへ移行する体験 |
| **出口** | 今の気分に一番近い色を直感で選び、「いってらっしゃい」で送り出される | 次の予定へ、気持ちを切り替える儀式 |
| **After(数分後)** | 次の予定に、リセットされた状態で入っていける | Fastのパフォーマンスへの実感的な貢献(極地反転) |
| **ギャラリー(夜/週末)** | これまで選んできた色が、一期一会の1枚の絵として育っている。AIが多面的にその絵(＝その期間の自分)を語り合う | 良い悪いのジャッジなしに、自分の積み重ねを受容できる体験 |
| **完成・保存** | 「もう十分」と感じたら完成ボタンを押し、絵をギャラリーに残す | 「ある期間の自分」を、否定も肯定もせず記録として持てる安心感 |

## この明文化から見えること

- **Fastの言語(入口)とSlowの体験(本体)の橋渡し**が、価値提案の核。単なる「休憩アプリ」ではなく「パフォーマンスのためのSlow」という位置づけがFast層への訴求力になっている。
- **「続けられること」自体が価値**になっている(評価されない、正解がない、時間を作らなくていい)。これはペルソナ②の悩みに直接応える設計。
- **「今の自分をジャッジせず受容する」**という体験価値は、ペルソナ①③が抱える「自分の感情を後回しにする/気づく暇がない」という課題に対する直接的な処方になっている。
